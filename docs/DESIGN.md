# Desktop design

**Platform:** Ubuntu/Linux, Qt 6 Widgets. **Audience:** engineers inspecting serial MAVLink traffic.

**Direction selected by the user:** Modern dashboard, clearly separated regions, more breathing room and moderately larger typography. The **ui-ux-pro-max** search `modern operational dashboard spacious` returned an unsuitable landing-page structure; the focused style search `minimalism swiss dashboard` verified the **Minimalism & Swiss Style** profile. Its spacing, hierarchy, contrast and restrained accent guidance fits this desktop. Qt is not a supported stack in the dataset, so the actual native layout uses desktop design judgment rather than web/mobile framework rules.

- **Hierarchy:** app identity, compact UART bar, two-column workspace, status bar. **TX Dashboard** occupies a resizable left column; **RX Dashboard** occupies the larger right column. RX streams and decoded fields use a vertical splitter, keeping complete rows readable at the minimum window size. Advanced serial settings expand only on request.
- **UART configuration:** a compact row starts with a clean 200 px **Serial port** input filtered to show actively plugged hardware devices, followed by an adjacent icon-only refresh button, **Baud rate**, the framing/flow summary, **Advanced**, an elastic stretch, and a divider before connection state / Connect. The redundant UART heading is omitted; the summary aligns with the controls beside Baud rate. Inputs have persistent labels above them and 32 px control height; labels have a 6 px gap above controls, with 10 px top/bottom card padding; shared serial field labels use 12 px type. The refresh action has an accessible name and tooltip, and custom device/PTY paths remain editable.
- **Advanced disclosure:** **Advanced** expands a quiet inset section with four equally spaced labeled controls for data bits, parity, stop bits and flow control; **Hide details** collapses it without resetting values. The section states that values are editable while disconnected. The compact summary always includes the selected flow mode. The focused `form labels grouped settings` skill search verified associated labels and connection feedback guidance for all platforms; the precise Qt disclosure layout uses desktop design judgment.
- **Spacing:** 20 px outer horizontal margins, 16 px panel padding and workspace gap, 12 px internal rhythm; resizable dashboard and inspector splitters.
- **Typography:** platform sans-serif, 22 px app title, 18 px panel titles, 14 px controls, 15 px TX message names and 12 px supporting text. System fixed-pitch font for decoded identifiers and values. No network font dependency.
- **Light:** background `#edf1f8`, surface `#ffffff`, text `#20263b`, secondary text `#626c84`.
- **Dark:** background `#0d1422`, surface `#1b2333`, text `#edf0fa`, secondary text `#aab4cd`.
- **Actions:** indigo `#4f46e5` Connect/Add, teal `#087f6e` Start and red Stop all text. When connected, Disconnect switches to a quiet outlined action to distinguish it from the primary Connect state. Edit/Remove/Stop all sit above the TX list; Send once/Start/Stop stay at its bottom. Secondary actions have quiet outlined surfaces. Summaries report configured/running TX entries and displayed RX stream count.
- **TX cards:** a single delegate paints each existing row as a card containing ID, frame count, status, name, sender, target Hz and actual Hz. An interactive inline toggle button with play/stop icons sits directly on the status badge, allowing immediate stream start/stop on click with pointing cursor feedback. Actual transmission rate is highlighted when active. No per-entry widget allocation or transport changes. Selection uses an indigo border and tinted surface; hover, click, keyboard navigation and double-click editing remain available. Full identity/state is also exposed through tooltips and accessible text, including elided names and errors.
- **Data hierarchy:** RX streams and decoded fields each have a bordered frame and a dedicated title bar, with distinct header/body surfaces. Light title bars use `#e8eef8` with `#40536e` text; Dark uses `#25334b` with `#d6dfee` text. Data borders are `#bdcbdf` / `#4b5f7b`. Tones and selection are intentionally softer than the initial information-separation revision. Splitter gaps remain draggable without hover highlighting. The TX/RX splitter is 12 px wide. TX cards have stronger outlines, a state accent, a sender value emphasis and a divider above bold 14 px rates. The TX list has its own inset background. The status bar shows debug metrics in muted 12 px type on the main window background, with dynamic alert colors (red/amber) when CRC errors, queue backpressure or RX overflow are detected.
- **RX tables:** no cell grid, right-aligned numeric headers/values (ID, Count, Hz) with monospace system font, subtle row dividers and stronger selection. Stream activity uses a theme-aware vector LED indicator (green for fresh, amber for aging, muted for stale). Decoded and editable values use a shared delegate for regular blue-gray text (`#3f628b` / `#b2c8e2`), preserving native selection and editing. Changed field values are temporarily highlighted, and common protocol constants (such as HEARTBEAT autopilot/type/status enums) offer human-readable descriptions in tooltips.
- **Inspector:** explicit RECEIVED MESSAGES and DECODED FIELDS title bars; the latter also identifies the selected message. The unavailable unit column is hidden; its limitation remains in the inspector tooltip and documentation.
- **Empty states:** TX, RX and decoded-field viewports remain blank when no data is available, including filter results. No placeholder or guidance overlays are displayed. Panel titles, table headers and actions remain available.
- **Message editor:** two columns for searchable catalog and sender/timing/payload, with an explicit primary Save action, single-click payload editing, editable-value hint and inline validation.
- **Interaction:** indigo keyboard focus/selection, stable button bounds, native keyboard traversal, native editable controls, explicit disabled states. Icons, dropdown chevrons and numeric steppers use local theme-aware QPainter vectors; native interactions are retained. No animations, external assets or new dependencies.
- **Status:** text labels distinguish connected/disconnected/error, running/stopped, recent/stale and paused display; meaning does not depend on color.
- **Themes:** System follows Qt's application palette; explicit Light/Dark overrides are available. System detection depends on the desktop platform theme supplied to Qt.
- **Data stability:** RX rows update in place. The GUI requests at most one outstanding snapshot and refreshes at 5 Hz. Serial processing continues independently.

**Desktop minimum:** 1000 × 720. This is not a mobile interface.

**Information separation refinement:** the focused `surface separation contrast hierarchy` UX search verified Contrast Readability guidance for all platforms: use readable foregrounds and avoid gray-on-gray information. The returned web breadcrumbs guidance was unrelated and was not applied. Frames, tonal layers and label/value emphasis above follow desktop design judgment within the accepted Modern dashboard layout.

**Button focus:** pointer clicks use hover/pressed feedback without an extra focus outline. Tab/Backtab/shortcut focus or Space/Enter input enables one explicit focus border. Buttons retain native keyboard activation and focusability; border/padding changes preserve their overall bounds. The focused skill search `keyboard focus mouse button` verified Focus States guidance: keep a visible keyboard indicator instead of removing focus feedback globally.

**Reduced secondary copy:** the app subtitle, dialect badge and TX/RX footer descriptions are omitted. Message-specific tooltips retain TX delivery semantics and RX signature status; blank view areas have no tooltip. Empty-state guidance is omitted; Pause/Resume button feedback remains visible. The focused `text contrast dark mode` UX search verified all-platform readability guidance; status text retains the existing theme foreground on the main background.

**Workspace spacing:** the connection card has a 12 px gap before the TX/RX cards (previously 16 px); the header-to-connection gap remains 16 px. Shared serial field labels use 12 px type, while the compact framing summary remains 11 px.
